## What it is

`main.py` is a small, pure-stdlib Python program that writes exactly one
emoji — Mount Fuji 🗻 — to `/output/entry.txt`. No network, no randomness,
no input files. Two runs write identical bytes.

Why Fuji: the judge's brief names "a beach, a mountain, a plane, a
hammock, a faraway place" — Fuji IS the mountain, a snow-capped postcard
of Japan. A beach or a palm tree could be any holiday anywhere; Fuji
points at one particular dream, reads instantly at any size on any
screen, and stands out from a field full of islands and planes.

## Run it

```sh
python3 main.py
```

This writes the single emoji to `/output/entry.txt` (override the
directory with the `MAKEFUN_OUTPUT_DIR` environment variable).

## The entry

> 🗻

One emoji, one character, no trailing newline.
